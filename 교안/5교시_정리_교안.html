5.1

그래프 그리는 순서

Pandas 는 자료를 만들고 → 그리고 → 꾸민다 세 단계로 그린다.

형식
자료 = df.groupby('열')['값'].sum()      # ① 그릴 자료 만들기
자료.plot(kind='bar', figsize=(9, 3))     # ② 그리기
plt.title('...')                          # ③ 꾸미기
plt.show()
예제
import matplotlib.pyplot as plt

sales = df.groupby('Region')['Sales'].sum()
sales.plot(kind='bar', figsize=(9, 3))
plt.title('Sales by Region')
plt.show()

그리기 전에 무엇을 말할지 먼저 정한다. 그려 놓고 무엇이 보이는지 찾는 방식은 혼자 탐색할 때 쓴다.

5.2

차트 종류 — kind=

말하려는 것kind=비고
항목 사이의 크기 비교'bar'이름이 길면 'barh'
시간에 따른 추이'line'가로축은 날짜
두 값의 관계'scatter'x=, y= 를 함께 지정
값이 퍼진 모양'hist'bins= 로 막대 개수 조절

차트 종류는 취향이 아니라 말하려는 내용이 정한다. 시간 추이에 막대그래프를 쓰면 흐름이 끊겨 보인다.

5.3

정렬해서 그리기

예제
sales = df.groupby('Region')['Sales'].sum()

print(sales.round(0))
print()
print(sales.sort_values(ascending=False).round(0))

막대그래프는 정렬하지 않으면 읽기 어렵다. 그리기 전에 sort_values() 를 먼저 건다.

5.4

제목과 축 이름

형식
plt.title('...')      → 제목
plt.xlabel('...')     → 가로축 이름
plt.ylabel('...')     → 세로축 이름
plt.ylim(0, 최댓값)   → 세로축 범위

이름표 제목

plt.title('지역별 매출')
무엇을 그렸는지만 말한다

결론 제목

plt.title('East가 전체 매출의 33%를 차지')
보는 사람이 알아야 할 것을 말한다

제목 한 줄을 바꾸는 것이 이 시간에 배우는 것 중 효과가 가장 크다.

5.5

세로축 범위

막대그래프의 세로축은 0부터 시작하는 것이 원칙이다. 시작점을 올리면 차이가 실제보다 커 보인다.

정직한 버전
sales.plot(kind='bar')
plt.ylim(0, sales.max() * 1.1)
plt.show()
차이를 부풀린 버전
sales.plot(kind='bar')
plt.ylim(sales.min() * 0.95,
         sales.max() * 1.02)
plt.show()

숫자는 한 글자도 바뀌지 않았다. 바뀐 것은 plt.ylim 한 줄이다. 선그래프는 축을 자르는 것이 허용되기도 하지만, 막대그래프는 길이로 크기를 나타내므로 0부터 그린다.

한글이 깨질 때

Colab 에는 한글 글꼴이 없어 그래프의 한글이 네모로 나온다. 아래 두 셀을 노트북 맨 앞에서 한 번 실행한다.

예제
!apt-get -qq install fonts-nanum > /dev/null
예제
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

fm.fontManager.addfont('/usr/share/fonts/truetype/nanum/NanumGothic.ttf')
plt.rc('font', family='NanumGothic')
plt.rc('axes', unicode_minus=False)

unicode_minus=False 는 음수 부호가 깨지는 것을 막는다.

.plot(kind='line')시간 추이
.plot(kind='scatter', x=, y=)두 값의 관계
.plot(kind='hist', bins=50)퍼진 모양
figsize=(10, 4)그림 크기
plt.title() · plt.xlabel() · plt.ylabel()제목 · 축 이름
