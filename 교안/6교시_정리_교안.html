6교시 정리

통계분석 기초

이 시간에 쓴 코드와 실행 결과

6.1

두 집단의 평균 비교

형식
from scipy import stats

stats.ttest_ind(집단A, 집단B, equal_var=False)
예제
a = df[df['Discount'] > 0]['Profit']
b = df[df['Discount'] == 0]['Profit']

print(round(a.mean(), 2))
print(round(b.mean(), 2))
print(stats.ttest_ind(a, b, equal_var=False).pvalue)
실행 결과
-6.68
66.33

1.07e-56

1.07e-56 은 0을 55개 붙인 것보다 작은 수다. 우연으로 보기는 어렵다는 뜻이다.

equal_var=False 는 두 집단의 퍼진 정도가 다를 수 있다고 보는 방식이다. 보통 이쪽이 안전하다.

6.2

차이가 작을 때는 이렇게 나온다

예제
c = df[df['Segment'] == 'Consumer']['Profit']
g = df[df['Segment'] == 'Corporate']['Profit']

print(round(c.mean(), 2))
print(round(g.mean(), 2))
print(round(stats.ttest_ind(c, g,
      equal_var=False).pvalue, 3))
실행 결과
25.82
30.14

0.415

p = 0.415 는 “차이가 없다”는 뜻이 아니다. “다르다고 말할 근거가 부족하다”는 뜻이다.

눈으로 보면 4점 넘게 차이가 나지만, 그 정도는 우연히도 나올 수 있는 크기다.

6.3

p값이 아닌 것

흔한 오해실제
p=0.03 이면 내 주장이 맞을 확률 97%아니다. p값은 내 주장의 확률이 아니다
p=0.4 면 두 집단이 같다는 뜻아니다. 다르다고 말할 근거가 부족할 뿐이다
p가 작으면 차이가 크다아니다. 차이의 크기와 p값은 다른 이야기다

p값의 뜻은 하나뿐이다 — 두 집단이 사실 같다고 쳤을 때, 지금 본 정도의 차이가 우연히 나올 확률.

6.4

유의하다 ≠ 중요하다

데이터가 많아지면 아무리 작은 차이도 p값이 작게 나온다.

예제
import numpy as np
np.random.seed(0)

for n in [100, 1000, 100000]:
    A = np.random.normal(100,   10, n)
    B = np.random.normal(100.5, 10, n)
    p = stats.ttest_ind(A, B, equal_var=False).pvalue
    print(n, round(p, 4))
실행 결과
100      0.6195
1000     0.0769
100000   0.0000

실제 차이는 셋 다 0.5 로 같다. 표본이 커지자 p값만 작아졌다.

그래서 보고할 때는 p값과 차이의 크기를 함께 적는다 — “할인한 주문은 건당 이익이 73 낮습니다 (p < 0.001)”.

6.5

상관계수

형식
df['열1'].corr(df['열2'])      → -1 에서 +1 사이의 값
예제
print(round(df['Discount'].corr(df['Profit']), 3))
print(round(df['Sales'].corr(df['Profit']), 3))
+1 에 가깝다한쪽이 오르면 다른 쪽도 오른다
0 에 가깝다직선 관계가 약하다
-1 에 가깝다한쪽이 오르면 다른 쪽은 내린다
실행 결과
-0.22
0.243

할인율과 이익은 음의 관계이지만 −0.22 로 약하다. 숫자만 보지 말고 산점도를 함께 확인한다.

6.6

AI 에게 물어볼 때 넣을 다섯 가지

회사 데이터는 대개 올릴 수 없다. 대신 데이터가 어떻게 생겼는지 말로 설명한다.

요소무엇을 적나
① 상황무슨 일을 하는 조직이고 왜 궁금한가
② 알고 싶은 것한 문장으로
③ 데이터 형태한 행이 무엇인지, 열 이름과 종류, 행 수
④ 비교 대상집단이 몇 개인지, 짝지어져 있는지
⑤ 제약못 하는 것, 쓰는 도구

그리고 “이 방법이 맞지 않게 되는 경우” 를 꼭 함께 묻는다. AI 는 대체로 자신 있게 답하므로, 이 질문을 해야 스스로 조건을 붙인다.
